# Gennexbyte Office

Planning platform kantor virtual dan pusat kontrol AI agent untuk ekosistem Gennexbyte.

**Status: perencanaan.** Repository ini berisi dokumen rancangan; belum ada runtime agent, aplikasi web, atau deployment.

## Konsep

Satu lantai luas dengan ruangan per produk serta departemen Finance, Marketing, dan Director. Pemilik dan rekan pengelola memberi instruksi melalui web, memantau pekerjaan, dan mengambil keputusan tanpa membuka SSH untuk setiap tugas.

## Dokumen

- [Planning produk, arsitektur, dan implementasi](docs/PLANNING.md)

## Cakupan yang disepakati

- Produk: Gennexbyte, NxChat, NxBooth, platform SocialHub, dan aplikasi baru.
- Finance memakai aplikasi finance yang akan dikembangkan.
- Marketing mengelola promosi dan media sosial melalui SocialHub.
- Director adalah ruang kolaborasi pemilik dan rekan pengelola.
- Implementasi dan hosting dilanjutkan pada VPS milik pemilik.
- Tampilan kantor merupakan representasi data backend, bukan sumber status tersendiri.

Pilihan stack, kapasitas server, model AI, dan kebijakan persetujuan final belum ditetapkan. Lihat daftar keputusan terbuka dalam dokumen planning.
